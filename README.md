# 📸 Instagram Clone — Full Stack Application

A full-stack social media application inspired by Instagram, built using **React.js, Spring Boot, MySQL and WebSocket**.

The project includes user authentication, posts, likes, comments, stories, follow/follower functionality and real-time messaging.

## 🚀 Live Demo

🌐 **Frontend:** https://instagram-clone-fullstack-pi.vercel.app

📂 **GitHub Repository:** https://github.com/itspatelg/instagram-clone-fullstack

## ✨ Features

### 🔐 Authentication
- User registration and login
- Secure authentication
- Protected application features

### 📝 Posts
- Create posts
- View posts
- Like posts
- Comment on posts

### 👥 Follow System
- Follow users
- Unfollow users
- Follow/follower counts

### 📖 Stories
- Create and view stories

### 💬 Real-Time Chat
- Real-time messaging using **WebSocket**
- Live communication between users

### 📱 Responsive UI
- Responsive frontend interface
- Mobile-friendly navigation
